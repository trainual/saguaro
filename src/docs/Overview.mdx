# Saguaro

Saguaro is Trainual's core design system: the formalized foundation that we
have extracted into a library. This Storybook documents what the library
exports and how to use it.

It is separate from the app-based design system inside the Trainual app
([Trainual Storybook › Design System](https://trainual-storybook.s3.amazonaws.com/index.html?path=/docs/design-system-overview--guide)).

Today Saguaro ships tokens only. Components will move here from the app-based
design system over time, under a **Components** section next to Design Tokens.

## Sections

| Section | What's in it |
|---|---|
| [Design Tokens](?path=/docs/design-tokens-overview--guide) | Every token category, with a live preview of its values and guidance on which one to reach for. |

## Where to start

1. Read the [Design Tokens overview](?path=/docs/design-tokens-overview--guide) for the categories and how to choose between them.
2. Use the paintbrush in the toolbar to check your work against other brand
   palettes, including custom hex colors. Every page re-renders with the
   selected brand.
